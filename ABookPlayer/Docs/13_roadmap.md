# 13. Roadmap

| Priorität | Thema | Inhalt |
| --- | --- | --- |
| P0 | Quellcode-Verifikation | Aktuellen Projektstand öffnen, Builds/Tests erneut ausführen, Dokumentstatus mit Code abgleichen. |
| P0 | Import-Härtung | Größenlimits, ZIP-Bomb-Schutz, atomare Extraktion, Legacy-Adapter sauber trennen. |
| P1 | Player-Robustheit | Audio-Focus, Service-Neustart, Fortschritt, Kapitelgrenzen und Fehlerfälle prüfen. |
| P1 | UX-Feinschliff | Empty States, deutsche Fehlermeldungen, Accessibility, Tablet-Layouts. |
| P1 | Statistik | Hörzeit pro Tag/Woche, Gesamtzeit und Datenschutz-freie lokale Auswertung. |
| P2 | Export | Hörbuchordner in kanonisches .abook-Format exportieren. |
| Später | Plattformen | Android Auto, Wear OS, optionaler Server-Sync – nicht im MVP. |
